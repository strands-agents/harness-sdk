Bidirectional streaming lets an application send input and receive model output at the same time over an open connection. The conversation can continue across multiple responses, and new input can arrive while the model is responding or tools are running.

Voice is a common use case: microphone audio flows to the model while speech and transcripts flow back. A user can interrupt the assistant, change the request, and keep talking. Applications can also send text and images while receiving streamed output, depending on the model's supported inputs and outputs.

## Get started

`BidiAgent` manages the model connection, runs tools, and maintains conversation history. Your application supplies input and handles output events, either directly through `send()` and `receive()` or through I/O streams connected with `run()`.

The Python SDK supports [Amazon Nova Sonic](models/bedrock.mdx), [Google Gemini Live](models/google.mdx), and [OpenAI Realtime](models/openai.mdx). The quickstart uses Nova Sonic with local microphone and speaker I/O:
