Build a voice agent that listens through your microphone, speaks through your speakers, and calls tools during the conversation. You'll ask it for the current time, interrupt a spoken response, and end the conversation by saying goodbye.

This example uses Amazon Nova Sonic, the default `BidiAgent` model, and requires Python 3.12 or later. Use headphones to keep the assistant's audio out of your microphone, or enable [echo cancellation](io.mdx#audio-processing) when using speakers.

## Install the SDK

### Platform-specific audio setup

For microphone and speaker access, install the PortAudio system library:

<Tabs>
<Tab label="macOS">

```bash
brew install portaudio
```

</Tab>
<Tab label="Linux (Ubuntu/Debian)">

```bash
sudo apt-get install portaudio19-dev
```

</Tab>
<Tab label="Windows">

PyAudio's Windows wheels include PortAudio, so no separate system installation is needed.

</Tab>
</Tabs>

Then install the SDK with Nova Sonic and local audio I/O support:

```bash
pip install "strands-agents[bidi,bidi-io,bidi-pyaudio]"
```

## Configure credentials

Configure [AWS credentials](models/bedrock.mdx#credentials) with permission to invoke Nova Sonic, then set the region for this example:

```bash
export AWS_DEFAULT_REGION=us-east-1
```

## Run the agent

Save the following as `voice_agent.py`. The `get_current_time` tool reads your computer's clock, and `end_conversation` lets the model stop the conversation when you ask:

```python
import asyncio
from datetime import datetime

from strands import ToolContext, tool
from strands.bidi.agent import BidiAgent
from strands.bidi.io import AudioIO


@tool
def get_current_time() -> str:
    """Get the current date and time in the computer's local time zone."""
    return datetime.now().astimezone().isoformat(timespec="seconds")


@tool(context=True)
def end_conversation(tool_context: ToolContext[BidiAgent]) -> str:
    """End the conversation when the user asks to stop or says goodbye."""
    tool_context.agent.cancel()
    return "Ending conversation."


async def main() -> None:
    agent = BidiAgent(tools=[get_current_time, end_conversation])
    audio_io = AudioIO()
    await agent.run(inputs=[audio_io.input()], outputs=[audio_io.output()])


asyncio.run(main())
```

Start it from your terminal:

```bash
python voice_agent.py
```

[`AudioIO`](io.mdx#audio-io) captures your microphone, plays the assistant's speech, and displays transcripts and tool call names in the terminal.

## Try a conversation

Ask **“What time is it?”** to try the clock tool. The agent can call `get_current_time` and use its result in the spoken answer.

### Barge-in

Ask **“Tell me three things to do in Lisbon.”** While the assistant is speaking, say **“Actually, make that Paris.”**

Speaking over the assistant demonstrates *barge-in*. The model signals the interruption, and `AudioIO` clears queued audio so playback stops promptly. You can change direction without waiting for the previous response to finish. See [Barge-in](events.mdx#barge-in-1) for the event and playback behavior.

### Graceful shutdown

Say **“Goodbye”** when you're finished. When the model calls `end_conversation`, the agent processes the cancellation request after the tool group finishes. `run()` then stops the agent and its I/O streams and returns. You can also press Ctrl-C to end the run from the terminal.

To customize the conversation, continue with [BidiAgent](agent.mdx) and [I/O Streams](io.mdx).
