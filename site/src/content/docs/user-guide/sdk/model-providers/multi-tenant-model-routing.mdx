An agent that serves several tenants (the customers of your application) often needs
three things from its models at once. It needs a small model for easy requests and a
stronger one for hard requests, a backup provider when a model fails, and a rule that
keeps each tenant on the models it has approved. This guide builds all three on one
[model router](./model-routing.md), with one tool set and one tracing configuration.

The examples use Amazon Nova Lite on [Amazon Bedrock](./amazon-bedrock.md) as the small
model, Claude Sonnet 5 on [Anthropic](./anthropic.md) as the strong model, and
[OpenAI](./openai.md) as the backup. A decision model picks between the small and the
strong model: Strands Decider on your machine, or another decision model you choose.
Configure AWS credentials with Amazon Bedrock access and set `ANTHROPIC_API_KEY` and
`OPENAI_API_KEY` before running them.

## Configure tracing once

Configure tracing before you create the agent. Every model call becomes a span that
records the model that served it in `gen_ai.request.model`, and every routing decision
becomes a `decision` span, so one configuration covers every candidate the router picks
and every choice it makes.

## Describe each candidate for the policy

Give each candidate a description for the decision model and metadata for the tenant
policy. Here `provider` decides which tenants may use the candidate, and `tier` marks
the backup so the opening selection never picks it.

<Tabs>
<Tab label="Python">
```python
from strands.models import BedrockModel, RoutingCandidate
from strands.models.anthropic import AnthropicModel
from strands.models.openai import OpenAIModel

fast = BedrockModel(model_id="us.amazon.nova-lite-v1:0")
strong = AnthropicModel(model_id="claude-sonnet-5", max_tokens=1024)
backup = OpenAIModel(model_id="gpt-5.4")

candidates = [
    RoutingCandidate(
        fast,
        name="fast",
        description="Short factual questions and order lookups.",
        metadata={"provider": "bedrock", "tier": "primary"},
    ),
    RoutingCandidate(
        strong,
        name="strong",
        description="Multi-step reasoning, trade-offs, and recommendations.",
        metadata={"provider": "anthropic", "tier": "primary"},
    ),
    RoutingCandidate(
        backup,
        name="backup",
        description="Serves requests when the primary provider is unavailable.",
        metadata={"provider": "openai", "tier": "backup"},
    ),
]
```

## Enforce the tenant policy in the routing strategy

Put the policy in a custom routing strategy. The strategy reads the tenant from
invocation state and keeps only the candidates that tenant may use. On the first attempt
it asks a decision model which allowed candidate fits the request. After a model
failure it asks `FallbackStrategy` for the next allowed candidate, backup first, so a
hard request never drops to the small model. When no candidate qualifies, it raises an
error and logs the refusal.

The decision model is any Strands `DecisionModel`. The strategy only calls its `ask`
method, so you choose the implementation in one line (see the next section).

<Tabs>
<Tab label="Python">
```python
import json
import logging
from dataclasses import replace
from typing import Any

from strands.decisions import DecisionModel
from strands.models import FallbackStrategy, RoutingCandidate, RoutingContext

audit_log = logging.getLogger("tenant_policy")

TENANT_PROVIDERS = {
    "customer-a": {"bedrock", "anthropic", "openai"},
    "customer-b": {"bedrock"},  # requests stay in Amazon Bedrock
}


class TenantPolicyError(Exception):
    """No candidate satisfies the tenant's model policy."""


class TenantPolicyStrategy:
    def __init__(
        self, decisions: DecisionModel, *, decisions_provider: str | None = None
    ) -> None:
        # decisions_provider: where the decision model sends the request, or None
        # when it runs on your own infrastructure
        self._decisions = decisions
        self._decisions_provider = decisions_provider
        self._fallback = FallbackStrategy()

    async def select(
        self,
        context: RoutingContext,
        **kwargs: Any,
    ) -> RoutingCandidate | None:
        tenant = context.invocation_state.get("tenant")
        providers = TENANT_PROVIDERS.get(tenant, set())
        allowed = [
            c for c in context.candidates
            if (c.metadata or {}).get("provider") in providers
        ]
        if not allowed:
            audit_log.warning("tenant=<%s> | no allowed model, refusing call", tenant)
            raise TenantPolicyError(f"tenant {tenant!r} has no allowed model")

        if context.attempts:
            # Fail over to the backup first, so a hard request never drops to the
            # small model
            backups = [c for c in allowed if (c.metadata or {}).get("tier") == "backup"]
            others = [c for c in allowed if (c.metadata or {}).get("tier") != "backup"]
            scoped = replace(context, candidates=backups + others)
            choice = await self._fallback.select(scoped, **kwargs)
        else:
            primaries = [
                c for c in allowed if (c.metadata or {}).get("tier") == "primary"
            ] or allowed
            choice = primaries[0]
            if len(primaries) > 1 and self._may_decide(providers):
                try:
                    choice = await self._decide(context, primaries)
                except Exception as error:
                    audit_log.warning("error=<%s> | decision failed", error)
        audit_log.info(
            "tenant=<%s>, candidate=<%s>, attempt=<%s> | routing decision",
            tenant,
            choice.name if choice else None,
            "retry" if context.attempts else "first",
        )
        return choice

    def _may_decide(self, providers: set[str]) -> bool:
        # The decision model reads the request, so it must be a provider the tenant allows
        return self._decisions_provider in (None, *providers)

    async def _decide(
        self,
        context: RoutingContext,
        primaries: list[RoutingCandidate],
    ) -> RoutingCandidate:
        request = next(
            (
                "".join(block.get("text", "") for block in message["content"])
                for message in reversed(context.messages)
                if message["role"] == "user"
            ),
            "",
        )
        state = json.dumps({
            "latest_request": request,
            "candidates": [
                {"name": c.name, "description": c.description} for c in primaries
            ],
        })
        result = await self._decisions.ask(
            state,
            {
                "model": {
                    "question": "Which candidate should handle the latest request?",
                    "choices": [c.name for c in primaries],
                    "uncertainty": False,
                }
            },
            invocation_context=context.invocation_context,
        )
        picked = result.answers.get("model")
        return next((c for c in primaries if c.name == picked), primaries[0])
```

A `BeforeModelCallEvent` hook looks like the natural place for this check. But the
router picks the model after that hook runs, so the hook cannot see which candidate
will serve the call. The same holds for a `before_model_call` intervention, which runs
on that event. The strategy sees the candidates, and the policy then also applies on
failover: `customer-b` never falls back to Anthropic or OpenAI, even when Amazon Bedrock
fails.

The decision model reads every request, so the strategy only asks it for tenants that
allow its provider. A decision model on your own infrastructure, like Strands Decider,
can serve every tenant. With one allowed model, such as for `customer-b`, the strategy
skips the decision.

## Choose the decision model

[Strands Decider](https://github.com/strands-labs/strands-decider) is an open-source
decision model that picks between options instead of generating text, so it answers
faster and costs less than an LLM judge. Run it as a local server, which loads the model
weights on first start:

```bash
pip install strands-decider
strands-decider serve StrandsAgents/strands-decider-2B-qwen3.5-v1-2610
```

Then wrap the server as a Strands `DecisionModel` by implementing `_ask`. The base class
traces each call as a `decision` span and adds its usage to the request.

<Tabs>
<Tab label="Python">
```python
import asyncio
import json
import urllib.request
from typing import Any

from strands.decisions import (
    DecisionInput,
    DecisionMetadata,
    DecisionModel,
    DecisionResult,
    Question,
)


class StrandsDecider(DecisionModel):
    """Asks choice questions of a `strands-decider serve` server."""

    def __init__(self, url: str = "http://localhost:8000/v1/systemone") -> None:
        super().__init__()
        self.url = url

    def _post(self, body: dict[str, Any]) -> dict[str, Any]:
        request = urllib.request.Request(
            self.url,
            data=json.dumps(body).encode(),
            headers={"content-type": "application/json"},
        )
        with urllib.request.urlopen(request, timeout=30) as response:
            return json.loads(response.read())

    async def _ask(
        self,
        state: DecisionInput,
        questions: dict[str, Question],
        **kwargs: Any,
    ) -> DecisionResult:
        if any(q["choices"] == "boolean" for q in questions.values()):
            raise ValueError("StrandsDecider answers choice questions only")
        wire = {
            qid: {
                "type": "choice",
                "instructions": q["question"],
                "criteria": {choice: None for choice in q["choices"]},
            }
            for qid, q in questions.items()
        }
        reply = await asyncio.to_thread(self._post, {"state": state, "questions": wire})
        usage = reply["usage"]
        return DecisionResult(
            # The server always picks one of the question's choices
            answers={qid: reply["answers"][qid]["choice"] for qid in questions},
            metadata=DecisionMetadata(latency_ms=int(reply["latency_ms"])),
            usage={
                "inputTokens": usage["input_tokens"],
                "outputTokens": usage["output_tokens"],
                "totalTokens": usage["input_tokens"] + usage["output_tokens"],
            },
        )
```

Wrap the [OpenAI Decisions API](https://platform.openai.com/docs/guides/decisions) the
same way to route with OpenAI's hosted decision model.

<Tabs>
<Tab label="Python">
```python
import time
from typing import Any

from openai import AsyncOpenAI  # a version that includes client.decisions
from strands.decisions import (
    DecisionInput,
    DecisionMetadata,
    DecisionModel,
    DecisionResult,
    Question,
    Uncertain,
)
from strands.types.exceptions import StructuredOutputException


class OpenAIDecisionModel(DecisionModel):
    def __init__(self, model_id: str = "gpt-6-luna") -> None:
        super().__init__()
        self._model_id = model_id

    async def _ask(
        self,
        state: DecisionInput,
        questions: dict[str, Question],
        **kwargs: Any,
    ) -> DecisionResult:
        if any(q["choices"] == "boolean" for q in questions.values()):
            raise ValueError("OpenAIDecisionModel answers choice questions only")
        started = time.perf_counter()
        # A client per call: each synchronous agent call runs its own event loop
        async with AsyncOpenAI(timeout=30) as openai:  # reads OPENAI_API_KEY
            response = await openai.decisions.create(
                model=self._model_id,
                input=state,
                questions=[
                    {
                        "type": "choice",
                        "name": question_id,
                        "instructions": question["question"],
                        "choices": [{"value": c} for c in question["choices"]],
                    }
                    for question_id, question in questions.items()
                ],
            )
        answers: dict[str, str | bool | Uncertain] = {}
        for answer in response.answers:
            question = questions[answer.name]
            if answer.type == "choice" and answer.choice in question["choices"]:
                answers[answer.name] = answer.choice
            elif question.get("uncertainty", True) is not False:
                answers[answer.name] = Uncertain()
            else:
                raise StructuredOutputException(
                    f"question id=<{answer.name}> | no valid answer"
                )
        return DecisionResult(
            answers=answers,
            metadata=DecisionMetadata(
                latency_ms=int((time.perf_counter() - started) * 1000)
            ),
            usage={
                "inputTokens": response.usage.input_tokens,
                "outputTokens": response.usage.output_tokens,
                "totalTokens": response.usage.total_tokens,
            },
        )
```

## Run the agent for a tenant

Attach the router as the agent's model and pass the tenant with each request. This
example reuses `candidates`, `TenantPolicyStrategy`, and `StrandsDecider` from the
previous sections and shows each routing decision in the log.

<Tabs>
<Tab label="Python">
```python
import logging

from strands import Agent, tool
from strands.models import ModelRouter

logging.basicConfig(format="%(message)s")
logging.getLogger("tenant_policy").setLevel(logging.INFO)


@tool
def lookup_order(order_id: str) -> dict:
    """Look up the shipping status of an order, such as A-1001."""
    orders = {"A-1001": {"status": "shipped", "eta": "Nov 6"}}
    return orders.get(order_id, {"status": "not found"})


strategy = TenantPolicyStrategy(StrandsDecider())
router = ModelRouter(models=candidates, strategy=strategy)
agent = Agent(model=router, tools=[lookup_order])

agent("Where is order A-1001?", invocation_state={"tenant": "customer-a"})
```

A typical log shows:

```text
tenant=<customer-a>, candidate=<fast>, attempt=<first> | routing decision
```

A tenant with no policy, such as `unknown-customer`, gets `TenantPolicyError` before any
model runs, and the log records the refusal:

```text
tenant=<unknown-customer> | no allowed model, refusing call
```

A model fails when its call raises an error instead of returning a response: the
provider is down or times out, the account is throttled after the agent's retries, or
the credentials or model access are invalid. The router reacts only to these errors, not
to the content of a response.

When a model fails, the router asks the strategy again with the failed attempt. If Claude
Sonnet 5 fails on a hard request, `customer-a` moves to the OpenAI backup, not to Nova
Lite. If Nova Lite fails, `customer-b` has no candidate left, so the original model error
reaches the caller.

Example:

```text
tenant=<customer-a>, candidate=<strong>, attempt=<first> | routing decision
tenant=<customer-a>, candidate=<backup>, attempt=<retry> | routing decision
tenant=<customer-b>, candidate=<fast>, attempt=<first> | routing decision
tenant=<customer-b>, candidate=<None>, attempt=<retry> | routing decision
```
