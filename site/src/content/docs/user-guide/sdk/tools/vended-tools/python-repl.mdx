Runs model-generated Python through the agent's [sandbox](../../sandbox/index.mdx) by calling `sandbox.execute_code(code, "python3")` (`sandbox.executeCode(code, 'python3')` in TypeScript). It returns `output` (stdout), `error` (stderr, including tracebacks), and `exit_code`. Each call runs in a fresh interpreter, so variables, imports, and definitions do not persist across calls. Files written to the sandbox filesystem do persist, so the model can checkpoint intermediate results to disk and load them in a later call.

_Supported in: Node.js on Unix/Linux/macOS (TypeScript), Python._

:::caution[Security Warning]
This tool executes arbitrary Python code. Without a [Sandbox](../../sandbox/index.mdx), code runs with the full permissions of the process. Only use with trusted input and consider running in a [sandboxed environment](../../sandbox/index.mdx) for production.
:::

```python
from strands import Agent
from strands.sandbox.docker import DockerSandbox
from strands.vended_tools import make_python_repl

python_repl = make_python_repl(
    sandbox=DockerSandbox("my-container"),  # bind at creation instead of reading agent.sandbox
    language="python3.12",  # interpreter on the sandbox's PATH
)
agent = Agent(tools=[python_repl])
```
