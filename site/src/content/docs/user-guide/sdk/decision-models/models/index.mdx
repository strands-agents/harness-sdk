To change what answers your questions, you change the decision model class. Every class
takes the same [questions](../questions.mdx) and returns the same result, so the rest of
your code stays as it is.

## Built-in decision models

| Decision model | Class | Answers with | Reports |
| --- | --- | --- | --- |
| [LLM decision model](llm.mdx) | `LLMDecisionModel` | Any model provider | Latency, token usage |

## Custom decision models

To answer questions with your own backend, such as a rules engine or a classifier you
host, subclass `DecisionModel` and implement `_ask`. It receives the input and the
questions and returns a result with one answer per question and the call's latency. The
base class validates the questions before your method runs, records the
[decision span](../observability.mdx) around it, and, when `ask` receives an invocation
context, adds the reported token usage to that request.

This decision model answers yes/no questions by checking the input for keywords:

<Tabs>
<Tab label="Python">

```python
import asyncio
import time

from strands.decisions import DecisionMetadata, DecisionModel, DecisionResult


class KeywordDecisionModel(DecisionModel):
    """Answers yes when the input contains any of the keywords."""

    def __init__(self, keywords: list[str]):
        self.keywords = keywords

    async def _ask(self, state, questions, **kwargs):
        started = time.perf_counter()
        text = str(state).lower()
        found = any(keyword in text for keyword in self.keywords)
        return DecisionResult(
            answers={question_id: found for question_id in questions},
            metadata=DecisionMetadata(
                latency_ms=round((time.perf_counter() - started) * 1000)
            ),
        )


async def main():
    decisions = KeywordDecisionModel(["refund", "charged twice"])
    result = await decisions.ask(
        "I was charged twice for order 1182.",
        {"billing": {"question": "Is this a billing issue?", "choices": "boolean"}},
    )
    print(result.answers)


asyncio.run(main())

# Output:
# {'billing': True}
```

This example only handles yes/no questions. A decision model that also handles
multiple-choice questions returns one of each question's labels, or `Uncertain` when the
question allows it. The base class doesn't check the answers your method returns.
