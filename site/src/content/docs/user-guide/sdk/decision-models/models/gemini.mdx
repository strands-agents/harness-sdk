`GeminiDecisionModel` answers questions with Google's
[Gemini Decisions API](https://ai.google.dev/gemini-api/docs/decisions-api)
(`gemini-decision-1`). The API scores each question's choices instead of generating text,
so every answer comes with a probability for each choice and a confidence. All the
questions in one `ask` go in a single request.

## Configuration

| Option | Description |
| --- | --- |
| `apiKey` | Your Gemini API key. Defaults to the `GEMINI_API_KEY` environment variable. |
| `modelId` | The decision model. Defaults to `gemini-decision-1`. |
| `defaultMinConfidence` | The minimum confidence for questions that don't set their own. Defaults to `0.75` for yes/no questions and `0.5` for multiple-choice questions; a value you pass applies to both. |
| `fetch` | A custom `fetch` implementation, for example to route requests through a proxy. |

## Confidence

The confidence is Gemini's own: the probability of the top answer. `metadata.confidence`
reports it, and a [minimum confidence](../questions.mdx) is compared against it.

| Question | Confidence | Range |
| --- | --- | --- |
| Yes/no | `max(p, 1 - p)`, where `p` is the probability of yes | `0.5` to `1` |
| Multiple choice | The probability of the chosen option | `1 / number of choices` to `1` |

The default of `0.75` makes a yes/no answer `Uncertain` when the probability of yes is
between `0.25` and `0.75`. Multiple-choice questions default to `0.5`, so a clear favorite,
such as `0.7` of four options, is still returned. Confidence scales differ between decision models, so retune
your thresholds when you switch to Gemini from another decision model.

Gemini rounds each probability to about two significant figures, so a multiple-choice
answer's probabilities can sum to slightly more or less than 1. The decision model
accepts a sum within `0.05` of 1 and returns the probabilities as Gemini sent them.

## Input

A string is sent as the request's text input. Content blocks and messages are sent as
JSON text, because the API doesn't accept conversation history. Image, audio, video, and
document bytes aren't supported.

## Errors

| Response | Error |
| --- | --- |
| Gemini blocked the input (an HTTP 400 safety error, or `prompt_feedback.block_reason`) | `ModelError`, with Gemini's reason in the message |
| Rate limited or temporarily unavailable (HTTP 429, 503, or 529) | `ModelThrottledError` |
| Request too large (HTTP 413) | `ContextWindowOverflowError` |
| Any other failed request, or an answer that doesn't match its question | `ModelError` |
