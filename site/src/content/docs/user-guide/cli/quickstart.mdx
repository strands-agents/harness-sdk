In this quickstart, you install the Strands CLI, connect a model provider, and start a chat with the default agent.

## Before you start

- Install Node.js 22.12 or later.
- Get credentials for a model provider, for example an AWS profile with access to Amazon Bedrock.

## Install the CLI

```bash
npm install -g @strands-agents/cli
```

## Connect a model provider

Run `strands`. When setup opens, select **Quickstart**:

1. **Select a provider.** The CLI finds the credentials that you have already, for example an AWS profile or an `OPENAI_API_KEY` in your environment.
2. **Select a model.** Search the models of the provider, or keep the default.
3. **Select Save and Launch.** The chat opens.

To change more than the model, select **Customize** instead. It shows the name, the instructions, the tools, the plugins, the context and memory, and the tool permissions of the agent.

## Chat with the agent

Type a task and push Enter, for example "make a list of the TODO comments in this folder".
Before most tool calls, the CLI asks for your approval: **Allow once**, **Always allow**, **Deny once**, or **Always deny**. Reads of files in the current folder do not need an approval.
Type `/help` to see the commands, and `/exit` to close the chat.

You can also give one task from your shell:

```bash
strands "summarize what this repo does"
```

## Change the agent for one run

Flags change one run, and the saved profile stays the same:

```bash
strands --model anthropic/claude-sonnet-5      # use a different model
strands --agent ./agent.ts                     # use an agent file
```

To save a change, type `/setup` in a chat. To get the agent as code, type `/export`. The CLI writes a TypeScript or Python project with an `agent` that you can import in your application.
