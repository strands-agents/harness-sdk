[PopNow](https://popnow.ai/api) is a pay-as-you-go API that serves Claude, GPT,
Gemini, DeepSeek, Kimi and other chat models through one API key, billed per token in
USD. Its chat endpoint is OpenAI-compatible and supports tool calling, so the same
agent code can switch between models from different labs by changing the model ID.

:::note[OpenAI compatibility]
This integration works through the SDK's built-in
[OpenAI provider](../../user-guide/sdk/model-providers/openai.mdx) pointed at
PopNow's OpenAI-compatible endpoint; there is no separate PopNow integration.
Compatible endpoints can have quirks that deviate from the exact OpenAI API spec, so
some features may behave differently than they do against OpenAI itself.
:::

## Installation

The OpenAI provider is an optional dependency. To install, run:

<Tabs>
<Tab label="Python">

```bash
pip install 'strands-agents[openai]'
```
</Tab>

## Usage

Create an [API key](https://popnow.ai/api/console/keys), export it as
`POPNOW_API_KEY`, and point the provider at PopNow's endpoint:

<Tabs>
<Tab label="Python">

```python
import os

from strands import Agent
from strands.models.openai import OpenAIModel

model = OpenAIModel(
    client_args={
        "api_key": os.environ["POPNOW_API_KEY"],
        "base_url": "https://api.popnow.ai/v1",
    },
    model_id="anthropic/claude-sonnet-5.5/chat",
)

agent = Agent(model=model)
response = agent("Explain tool calling in one sentence.")
print(response)
```

## Configuration

Two client settings connect the provider to PopNow:

* **API key**: from your [PopNow API console](https://popnow.ai/api/console/keys) (keys start with `sk-popnow-`)
* **Base URL**: `https://api.popnow.ai/v1`

Model IDs follow the `<lab>/<model>/chat` format, for example
`anthropic/claude-sonnet-5.5/chat`, `openai/gpt-6.1-terra/chat` or
`deepseek/v4-flash/chat`. The full list with prices is in the
[PopNow chat API docs](https://popnow.ai/docs/chat). For model parameters and other
provider options, see the [OpenAI provider](../../user-guide/sdk/model-providers/openai.mdx) guide.
