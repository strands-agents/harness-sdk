# Parity map: harness-ts specs to Rust tests

Baseline: harness-ts at `d6c5fae7c`. One row per harness-ts spec file; `Ported` counts TS `it(...)` cases (the tool and plugin rows count each `it.each` row; the core rows, `prompt.test.ts` to `agent.test.ts`, count an `it.each` table once) with a Rust test of the same intent, and `Gaps` lists the cases not ported and why. Paths are relative to `harness-ts/test/` and `harness-rs/strands-harness/src/`. The strands-ts map is [`strands-rs/docs/PARITY.md`](../../strands-rs/docs/PARITY.md).

Tool specs are also checked byte for byte against the TS-written `strands-rs/conformance/fixtures/harness_tools.json` (`tools/conformance_tests.rs`), and `HARNESS_CONTRACT` against `strands-rs/conformance/fixtures/harness_prompt.json` (`prompt.rs`). The session interop test (`tests/cross_sdk_session.rs`) is ignored by default; run it with `STRANDS_CONFORMANCE_TS=1 cargo test -p strands-harness --all-features --test cross_sdk_session -- --ignored`.
