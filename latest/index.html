/harness

Strands harness gives you a fully assembled agent with benchmarked defaults for the system prompt, tools, memory, session management, and context management, ready to take your idea to production.

  • Optimized defaults Every default is tuned and optimized. Spend your time on what makes your agent different, not on wiring up a harness piece by piece.

  • CLI or library Build an agent with the strands CLI, or import it in Python or TypeScript.

  • Customize anything Strands harness is built on the Strands Harness SDK, so nothing is a black box. Swap the model provider, override any default, add your own tools, or go all the way down to the primitives, with no rewrite.

/box

Strands Box is an open source sandbox for AI agents. It runs an agent such as the Strands CLI, Claude Code, or Codex CLI on your Mac, inside a sandbox the operating system enforces and under a Dogwood policy that decides its shell commands, file operations, network requests, and MCP calls. Box is in preview, so pin your version.

  • Enforced by the operating system Seatbelt on macOS sets which files and programs the agent can reach. Each tool and local MCP server runs in its own sandbox.

  • Rules that depend on history Dogwood rules can depend on what the box already recorded: allow git push only after the tests pass, or block uploads after the agent reads customer data.

  • Credentials injected at the gateway The egress gateway replaces credential placeholders with the real API keys and signs AWS requests. The agent holds only the placeholder.

/evals

Strands Evals lets you validate your agent before you ship. Score its output and its trajectory, find the root cause when a case fails, and simulate the users and tools it will meet in production.

  • Score 25+ built-in evaluators check a single answer, a full turn, or a whole conversation: output quality, tool selection, trajectory, goal success, and safety.

  • Diagnose When a case fails, detectors read the trace, find the span where things went wrong, and propose a root cause. Scoring says whether; diagnosis says why.

  • Simulate Simulators play the user or stand in for a tool, so you can score multi-turn behavior and run red-team attacks without a human in the loop.

FAQ

Start with five common questions about choosing, building, evaluating, and deploying an agent.

View all FAQs
Should I use Strands harness or the Strands Harness SDK?

Strands harness gives you a complete agent harness with defaults you can replace. Use the SDK when you want to choose and wire the components yourself.

Should I use Python or TypeScript?

Choose the SDK that matches your runtime. Both cover the core agent loop; check the feature pages for gaps such as Python-only bidirectional agents.

Should I build a custom tool or use an MCP tool?

Use a custom tool for code registered directly with an agent. Use an MCP tool when the capability comes from an MCP server. You can use both together.

How do I evaluate a Strands agent before production?

Use Strands Evals to run repeatable cases, score the agent's output and behavior, and diagnose failed runs before production.

Where can I deploy a Strands agent?

Strands agents run inside your application process, which you can deploy to a serverless platform, a container or Kubernetes environment, or a managed agent runtime.
